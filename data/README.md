# Data

## Source

- RavenStack SaaS Subscription & Churn Analytics
- Author: River @ Rivalytics
- Kaggle: `rivalytics/saas-subscription-and-churn-analytics-dataset`
- Synthetic, no PII, MIT-like educational/portfolio license

## Tables

| File | Rows | Use |
|---|---:|---|
| `ravenstack_accounts.csv` | 500 | account attributes + account churn flag |
| `ravenstack_subscriptions.csv` | 5,000 | plans, MRR/ARR, upgrades/downgrades |
| `ravenstack_feature_usage.csv` | 25,000 | feature events |
| `ravenstack_support_tickets.csv` | 2,000 | support experience |
| `ravenstack_churn_events.csv` | 600 | reasons, refunds, reactivations |

## Caveats

- `usage_id` has 21 duplicates; join feature usage through `subscription_id`
- Churn events are not account churn events one-for-one
- 13,198 usage events predate account signup; use the bounded activity window
- 676 events occur after a churned account's last churn date
- Feedback text is generic and not useful for text mining

`processed/` is generated by `analysis/build_extracts.py` for Tableau.
